1. 프로젝트 개요
- 이름: Routeez

- 배포 링크: https://routeez.netlify.app/

- 설명: 기존 서비스 '위밋 플레이스'의 핵심 기능을 클론 코딩하고, 사용자 편의를 위해 '중간지점부터의 여행지 최단 경로 탐색' 기능을 추가로 개선한 프로젝트입니다. 기존 서비스가 존재하나 자주 서비스 연결이 쉽지않았고 여정에 활용하기 최적화 되도록 기능을 추가하였습니다.

2. 주요 기능
- 다인원 주소 기반 중간지점 탐색: 여러 사용자의 출발 위치(GPS 및 주소 입력)를 기반으로 최적의 모임 장소(중간 지점)를 계산합니다.

- 여행 최단 경로 탐색: 선정된 중간 지점을 기점으로, 설정한 목적지와 경유지를 포함하는 최적의 이동 동선을 제공합니다.

3. Tech Stack
- Framework: Vite + React

- Language: JavaScript

- Styling: CSS

- Deployment: Netlify

4. 실행 방법
```

npm install

npm run dev

```
